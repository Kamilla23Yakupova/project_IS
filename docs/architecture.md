# Архитектура системы EduSpace

## Общая схема
- Клиент-серверная архитектура, веб-приложение.
- Серверная часть: Python (Django / FastAPI).
- Клиентская часть: HTML, CSS, JavaScript.
- СУБД: PostgreSQL.
- Веб-сервер: Nginx.
- ОС сервера: Linux.

## Основные подсистемы
1. Управление пользователями и авторизация.
2. Управление курсами и учебными материалами.
3. Работа с заданиями и тестами.
4. Учёт успеваемости и отчётность.
5. Администрирование.

## Основные сущности БД
Пользователь, Курс, Учебный материал, Задание, Ответ студента, Оценка, Учебная группа.
