\# Проект: Создание АИС дистанционного обучения «EduSpace»



\## Назначение проекта

Проект предназначен для разработки и внедрения автоматизированной информационной системы дистанционного обучения «EduSpace».

Цель — автоматизировать ключевые процессы обучения, централизовать учебные материалы и сократить время на подготовку и проверку заданий.



\## Структура папок

project\_IS/

├── docs/ # ТЗ 

├── management/ # Устав

├── src/ # Исходный код

├── tests/ # Тестовые сценарии и ПСИ

└── README.md

\## Как использовать

1\. Клонировать репозиторий: `git clone <URL>`

2\. Ознакомиться с Уставом проекта в папке `management/`

3\. Изучить ТЗ и Программу испытаний в папке `docs/`

4\. Код системы будет размещён в `src/` по мере готовности.
